## What is windOS Zen?

A beginner-friendly Debian-based distro: a live GNOME session, a
choose-your-desktop graphical installer (six editions, one ISO), and
windOS Boot with a one-key rescue desktop.

**Docs:** [`docs/`](docs/README.md) — start there, or jump to
[Installing](docs/install.md).

**Download:** see the Releases page.

## Building the ISO

Build with `live-build/build-iso.sh` inside a `debian:trixie` Docker
container (or on a Debian 13 host). See the script header and `docs/`
for details.
