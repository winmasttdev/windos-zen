# Live Session

Booting the ISO takes you straight into a ready-to-use **GNOME** desktop.
No login, no password prompts — it just works.

## What's inside

- **GNOME Shell** with the windOS look: dark theme, Dash to Dock, blurred
  shell, app indicators, and the default app set (Terminal, Files, System
  Monitor, Tweaks, and more).
- **NetworkManager** — Wi-Fi and wired networks from the top bar.
- **Calamares installer**, via the **Install windOS Zen** icon on the
  desktop and in the app grid.
- Firmware packages included, so most Wi-Fi cards and graphics work out
  of the box.

## No persistence — changes don't stick

The live session runs from RAM and the USB stick. Anything you create,
download, or change **disappears on reboot**. This is by design: the live
session is for trying things out and running the installer.

If you like what you see, click **Install windOS Zen** — your real system
is one wizard away ([Installing](install.md)).
